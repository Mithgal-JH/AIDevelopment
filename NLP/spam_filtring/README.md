# Spam Filter Bot (Corner Web Widget)

This project includes:

- Cosine Similarity classifier (Arabic examples)
- Naive Bayes classifier (English dataset)
- Logistic Regression classifier (English dataset)
- Simple webpage with a corner bot UI

## Run

1. Install dependencies:

```bash
pip install -r requirements.txt
```

2. Start app:

```bash
python app.py
```

3. Open:

http://127.0.0.1:5000
